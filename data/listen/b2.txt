=== l033 | B2 | 讲座 | Wie Large Language Models funktionieren | 大语言模型如何工作
intro: 一场面向大众的科普讲座片段。
voices: P=Florian:Professor
P: Ein großes Sprachmodell tut im Grunde etwas sehr Einfaches: Es sagt das nächste Wort vorher – genauer gesagt das nächste Token, also ein Wortstück. // 大语言模型本质上做的事很简单：预测下一个词——更准确地说是下一个 token，也就是词片段。
P: Dafür wurde es mit riesigen Textmengen trainiert. Aus diesen Daten hat es statistische Muster gelernt, wie Sprache aufgebaut ist und welche Inhalte häufig zusammen auftreten. // 为此它用海量文本进行了训练，从这些数据中学到了语言如何构成、哪些内容经常一起出现的统计规律。
P: Das erklärt auch das größte Problem dieser Modelle: Sie erzeugen Texte, die plausibel klingen, aber nicht unbedingt wahr sind. Man spricht dann von Halluzinationen. // 这也解释了这些模型最大的问题：它们生成的文本听起来合理，但不一定真实。这被称为“幻觉”。
P: Das Modell hat kein eingebautes Wissen darüber, ob eine Aussage stimmt. Es weiß nur, welche Fortsetzung wahrscheinlich ist. // 模型并没有内置的知识来判断一个陈述是否正确，它只知道哪种续写可能性大。
P: Eine verbreitete Gegenmaßnahme heißt Retrieval-Augmented Generation. Dabei sucht ein System zuerst passende Dokumente und gibt sie dem Modell zusammen mit der Frage. Das Modell soll dann nur auf Grundlage dieser Dokumente antworten und die Quellen angeben. // 一种常见的对策叫检索增强生成。系统先查找相关文档，连同问题一起交给模型。模型只能依据这些文档回答，并给出出处。
P: Das reduziert Halluzinationen deutlich, beseitigt sie aber nicht vollständig. Deshalb sollte man bei wichtigen Anwendungen – etwa in Medizin oder Recht – die Antworten automatisch oder von Menschen überprüfen lassen. // 这能明显减少幻觉，但不能完全消除。所以在重要的应用中，比如医疗或法律，应当让程序或人来核查答案。
P: Ein weiterer Punkt ist die Bewertung: Wer ein solches System einführt, braucht einen Testdatensatz mit bekannten richtigen Antworten, um zu messen, ob Änderungen das System besser oder schlechter machen. // 另一点是评估：引入这种系统的人需要一个已知正确答案的测试集，用来衡量改动让系统变好还是变坏。
---
