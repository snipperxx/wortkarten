=== l001 | A1 | 对话 | Im Café | 在咖啡馆点单
intro: 一位顾客在咖啡馆点饮料和蛋糕。
voices: K=Katja:Kellnerin, M=Conrad:Gast
K: Guten Tag! Was darf es sein? // 您好！您要点什么？
M: Guten Tag. Einen Kaffee, bitte. // 您好，请来一杯咖啡。
K: Mit Milch und Zucker? // 加牛奶和糖吗？
M: Nur mit Milch, bitte. Keinen Zucker. // 只加牛奶，不要糖。
K: Gern. Möchten Sie auch etwas essen? Wir haben heute Apfelkuchen. // 好的。您还想吃点什么吗？我们今天有苹果蛋糕。
M: Ja, ein Stück Apfelkuchen, bitte. Was kostet das zusammen? // 好，请来一块苹果蛋糕。一共多少钱？
K: Der Kaffee kostet zwei Euro achtzig und der Kuchen drei Euro fünfzig. Das macht sechs Euro dreißig. // 咖啡两欧八十，蛋糕三欧五十，一共六欧三十。
M: Kann ich mit Karte bezahlen? // 我可以刷卡吗？
K: Ja, natürlich. // 当然可以。
M: Hier, bitte. Und stimmt so. // 给您。不用找了。
K: Vielen Dank! Ich bringe Ihnen alles sofort. // 非常感谢！我马上给您端过来。
---
! Der Gast möchte Tee. => falsch // 他点的是咖啡（Einen Kaffee, bitte）。
! Der Gast nimmt Milch, aber keinen Zucker. => richtig // Nur mit Milch, bitte. Keinen Zucker.
? Was isst der Gast? => Apfelkuchen | Käsekuchen | ein Brötchen // ein Stück Apfelkuchen
? Wie viel kostet alles zusammen? => 6,30 € | 2,80 € | 3,50 € // Das macht sechs Euro dreißig.
? Wie bezahlt der Gast? => mit Karte | bar | gar nicht // Kann ich mit Karte bezahlen? – Ja, natürlich.
+ Was darf es sein? // 您要点什么？（店员常用）
+ das Stück, -e // 块、份
+ Das macht … // 一共……（钱）
+ Stimmt so. // 不用找了。

=== l004 | A1 | 电话 | Einen Termin beim Arzt machen | 打电话约医生
intro: 一位病人打电话到诊所预约。
voices: K=Katja:Praxis, M=Conrad:Herr Lin
K: Praxis Doktor Becker, guten Morgen. // 贝克医生诊所，早上好。
M: Guten Morgen, mein Name ist Lin. Ich möchte gern einen Termin machen. // 早上好，我姓林，我想预约。
K: Was haben Sie denn? // 您哪里不舒服？
M: Ich habe seit drei Tagen Halsschmerzen und Fieber. // 我嗓子疼、发烧三天了。
K: Oh, das tut mir leid. Können Sie heute um elf Uhr kommen? // 哦，真遗憾。您今天 11 点能来吗？
M: Um elf muss ich leider arbeiten. Geht es auch am Nachmittag? // 11 点我得上班。下午可以吗？
K: Ja, um halb vier ist noch ein Termin frei. // 可以，三点半还有一个空位。
M: Halb vier ist gut. // 三点半可以。
K: Waren Sie schon einmal bei uns? // 您以前来过我们这儿吗？
M: Nein, das ist das erste Mal. // 没有，这是第一次。
K: Dann bringen Sie bitte Ihre Versichertenkarte mit. // 那请带上您的医保卡。
M: Mache ich. Vielen Dank, auf Wiederhören! // 好的。非常感谢，再见！
---
? Was hat Herr Lin? => Halsschmerzen und Fieber | Kopfschmerzen | Bauchschmerzen // Ich habe seit drei Tagen Halsschmerzen und Fieber.
? Wann kommt Herr Lin zum Arzt? => um 15:30 Uhr | um 11 Uhr | um 13:30 Uhr // halb vier = 15:30
! Herr Lin war schon oft in der Praxis. => falsch // Das ist das erste Mal.
? Was soll er mitbringen? => seine Versichertenkarte | seinen Pass | ein Foto // Bringen Sie bitte Ihre Versichertenkarte mit.
+ die Praxis // 诊所
+ der Termin, -e // 预约
+ die Versichertenkarte // 医保卡
+ auf Wiederhören // 再见（电话里用）
